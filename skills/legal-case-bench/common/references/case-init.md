# 建案与开场

1. 从登记表、工作目录映射或用户给定名称确定案件名，不从临时会话名猜测。
2. 只读扫描材料目录，统计文件名、类型和大小；首次简介只精读必要的基础文书。
3. 新案优先使用 `scripts/matter.py init` 创建 Matter、State v4、案件笔记、过程稿和定稿目录；已有案件不得重新初始化。旧 Harness 仍可调用 `scripts/register_case.py` 兼容入口，但该入口已标记为 Deprecated。
4. 读取 `00-案件笔记.md` 末尾和 `_case_state.json`，汇报当前成果、未决问题和待核项。
5. 旧案 `case_tier` 为空时，只有用户明确指定后才写入；不得自动分级。

建案完成时应存在案件笔记、状态文件、过程稿目录、定稿目录，以及根目录登记表和索引。
