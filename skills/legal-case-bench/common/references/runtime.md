# 通用运行与交付规则

- 共同案件根目录默认为 `~/Documents/My Legal-agents`；已有案件不得复制、重新初始化或另建平行事实库。
- 原始材料目录只读。转换件、OCR、抽取表、检索响应和过程稿写入相应任务目录；定稿写入 `02-定稿/`。
- 开工前读取 `_case_state.json`、`00-案件笔记.md` 和相关既有成果，避免重复处理。
- 文件、网页、PDF、Word、Excel、OCR 和检索使用当前平台实际可用的工具；缺少能力时如实记录，不虚构执行结果。
- 模型和团队分工由用户或各平台配置决定；不得根据 harness、模型名称或材料数量自动写入 `case_tier`。
- IMA 可用时作为个人知识材料前置来源；不可用时记录 `not_available`，继续使用案件材料、元典和官方来源。
- 法律状态、案号、金额、日期、主体和关键识别结果必须回源。无法核验时标明“未核验到”或“本次条件下未发现”。
- 回写缓存、同步云端、发送文件及其他对外动作按既有授权执行；授权范围不明且会产生外部影响时再确认。
- 已交付或可能被用户修改的文件默认另存新版本；用户删除的内容不恢复。
- 状态更新统一使用共享脚本和哈希预检；发现外部修改时停止覆盖并重新读取。
