# 破产案件资产负债数据分析守则

1. 所有金额、日期、账户、债权和资产数据必须与原始材料二次验证、交叉对比后再输出；冲突不得静默抹平。
2. 资料不足时区分“材料记载、计算结果、模型推断和假设”，分别列出不同假设下的结果，不用零值替代缺失值。
3. 明确分析视角：管理人、债务人、债权人或投资人；视角不明确且会改变结论时再向用户确认。
4. 每个分析结论必须有数据或法律依据，并保留文件、页码、工作表或计算底稿定位。
5. 银行流水、对账单和密集表格按 `pdf-ocr-extractor` 的高精度路线处理；关键金额回看原页或异引擎复核。
6. 检索结果和法律分析不得直接写入案件事实；需要入账时重新核对原件并记录来源。
