# 法律检索来源阶梯与作业纪律（权威源）

> 本文件是本机法律检索纪律的**权威源**，使用相关技能时显式读取，适用于一切法律/法条/案例检索任务。
> legal-research、legalcase-search 等 skill 及 knowledge/workflows 中的检索表述如有出入，一律以本文件为准（skill 文件内的同步在技能迁移会话完成）。
> 当前平台通道：IMA（若已配置）、元典统一 MCP 和官方网页；使用元典前读取 `yuandian-mcp.md`。当前未接入的 IMA 或其他通道不得假称可用，历史缓存不能替代法律效力和裁判全文核验。

## 历史办案经验的边界

`_practice/` 的 Authority 与 Practice Note 仅供 Recall。命中历史经验后，须在当前 Matter 中重新联网核验法条真实性与现行效力、案例原文及案号/法院/裁判日期、事实可比性和具体适用性；无法联网时只作为研究线索，不得标为当前已核验依据。正式用于本案时再登记 `authority_refs[]`，不自动复制历史核验状态。

## 来源阶梯（效力递减，检索后必须给每条材料打效力标签）

| 层 | 来源 | 用途 | 约束 |
|---|---|---|---|
| A | 现行法律、司法解释、行政法规等规范文本 | 证明正式规则、要件、法律后果 | 核对效力、施行日、修订与过渡条款 |
| B | 法答网精选答问、最高法官载体 | 识别疑难问题审判口径 | 不等于司法解释或裁判依据 |
| C | 人民法院案例库入库案例、指导性案例 | 规则在典型事实中的适用 | 核验官方身份、案号、日期、要旨与全文 |
| D | 公报案例、最高法/高院典型案例、法院官方案例文章 | 补充裁判尺度、例外、实务路径 | 准确说明来源性质，不一律称指导性案例 |
| E | 可核验裁判文书、法院报刊、权威出版物 | 观察裁判实践与说理 | 单案不当然代表统一规则，注意旧法与选择偏差 |
| F | 学术论文、律师文章、商业数据库、媒体转载 | 发现争议、关键词、线索 | 回溯上游原文，只作观点/辅助 |

## 检索前置：问题卡（动手检索前先填）

把问题压缩为一句可裁判的问题，并记录：① 主体关系、核心行为、请求权/抗辩权；② 案由或可能案由、实体争点、程序阶段；③ 关键事实门槛、举证责任、证据缺口；④ 行为发生日/起诉日/审理日等**新旧法连接点**；⑤ 交付需求（可否/胜算/路径/风险/文书观点/案例清单）。**以任务发生日为检索截止日。**

## 检索顺序与通道（按当前环境可用通道执行）

1. **IMA 线索前置**：若 `ima` MCP 已配置，先检索个人知识材料、文章和既有研究；未配置时在案件检索清单中记录 `ima: not_available` 并继续，不得声称已查询。
2. **规范与法答网**：核验案件适用时点的正式规范；检索法答网精选答问并准确说明其不是司法解释。未命中须记录检索词，不以沉默推导结论。
3. **案例检索（C 层）**：使用元典统一 MCP 检索候选，再回溯人民法院案例库、法院官网或裁判全文核验案例身份、案号、日期、事实、说理与结果。搜索摘要只用于筛选。
4. **补检其他权威案例（D/E 层）**：公报案例、最高法或高院典型案例、法院官方案例文章和可核验裁判文书。
5. **官方网页补充与反向溯源**：使用“法院 + 关键词”“理解与适用 + 关键词”等定位上游来源，核验发布机关原页。

**案件成果落盘**：与具体案件有关的检索必须同时遵守 `research-artifacts.md`，保存去凭据原始响应、结构化结果、检索报告和 `_case_state.json` 成果指针。

## 反向/边界材料强制检索

每个争点必须**同时寻找支持、反对与边界材料**。优先选层级高、时间新、事实相似、说理完整、现行法下作出且能直接回答争点的案例；尽量取得至少一项正向 + 一项反向/边界材料。**未找到反向案例只写"本次检索未发现"，不得宣称"没有相反裁判"。** 材料冲突时不简单投票，比较制度、法版本、位阶、时间、层级、事实相似度、说理一致性与完整度后，说明采纳或保留理由。

## 引证纪律与诚实表述

**引证要素：**
- 法条：全称 + 条号 + 效力状态 + 必要款项
- 法答网：标题 + 批次/栏目 + 日期 + 答疑专家/发布机关（若公开）+ 链接
- 案例：通道 + 名称 + 案号 + 法院 + 裁判日期 + 来源身份 + 可复核链接/字段
- 网页：标题 + 发布者 + 日期 + 链接，动态内容注明检索截止日

**诚实表述：**
- 无法核验时写"**未核验到**"或"在本次检索条件下未核验到"；案例身份无法在原条目核验时写"**间接定位，未完成案例库原条目核验**"。**不得写"案例库没有相关案例"。**
- 不虚构法答网批次、专家姓名、案例库编号、案号、裁判日期、条文状态、链接。
- 对用户提供的文章只提取问题、关键词、线索，仍须独立检索，不直接沿用其结论。
- 知识库/二手内容与权威源冲突时，以最新权威源为准并明确标注。

## 完成前自检清单

输出前逐项勾选：① 明确检索截止日与新旧法连接点；② 已记录 IMA 可用性；③ 已报告法答网命中或未命中；④ 已记录元典及官方来源通道或降级原因；⑤ 已核验案例身份与裁判全文状态；⑥ 已核验案件适用规范并检索至少一种其他权威来源；⑦ 已做官方网页补充；⑧ 已寻找反向或边界材料；⑨ 未把法答网写成司法解释、未把普通案例写成指导性或入库案例；⑩ 未只依据搜索摘要、AI 摘要或转载标题；⑪ 未把旧法结论无说明迁移到新法；⑫ 已把规则适用于本案事实；⑬ 已提供可复核来源并说明事实缺口、程序风险和核验状态；⑭ 案件检索成果已按共同协议落盘。
